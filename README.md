# Chess Universe — Legacy Full-Stack Build

<!-- repo-intro:start -->
**Project snapshot:** An earlier full-stack Chess Universe implementation combining a browser chess client with Express, sessions, MongoDB-era persistence, Socket.IO, Stockfish, and automated tests.

**What it demonstrates:** JavaScript · Express · Socket.IO · chess.js/Stockfish · Jest.
<!-- repo-intro:end -->

## Portfolio context

This repository captures an earlier stage of the Chess Universe product and its move from a simple browser board toward authenticated multiplayer and engine-assisted play.

The actively developed version is **ChessUniverseV2**, which uses a newer React/TypeScript frontend and Supabase-backed trusted multiplayer architecture.

## Engineering areas represented here

- Chess rules and board interaction with `chess.js`
- Real-time communication with Socket.IO
- Express sessions and authentication
- MongoDB/Mongoose-era persistence
- Stockfish integration
- Jest/Supertest-based testing

## Run locally

Install dependencies and use the scripts defined in `package.json`.
